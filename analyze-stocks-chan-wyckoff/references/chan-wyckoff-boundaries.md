## 缠论最低口径

采用后期较严格的结构顺序：

1. 按时间顺序处理K线包含；
2. 在处理后的K线上确认顶底分型；
3. 用统一笔标准连接交替分型；
4. 用特征序列划分线段，不用一笔提前确认线段结束；
5. 用至少三个连续、已完成的次级别走势重叠生成中枢；
6. 递归生成更高级别走势类型；
7. 先验证趋势和可比段，再判断背驰；
8. 逐项验证一、二、三类买卖点。

中枢初始三个构件的高低点分别为 `H1..H3` 与 `L1..L3`：

```text
ZD = max(L1, L2, L3)
ZG = min(H1, H2, H3)
```

当 `ZD <= ZG` 时形成核心区 `[ZD,ZG]`。另用 `[DD,GG]` 表示全部震荡外沿，不把核心区和外沿混用。

走势类型：

- 盘整：只含一个该级别中枢；
- 趋势：至少含两个同向、互不重叠的同级别中枢；
- 最小结构满足只表示“具备完成条件”，不表示马上反转。

背驰边界：

- 没有趋势，没有严格趋势背驰；
- 后段需要与前段同向、同级且可比；
- 小级别背驰不能直接宣布大级别反转；
- MACD只能辅助已确定的结构分段。

买卖点边界：

- 一买/一卖：该级别下跌/上涨趋势背驰终点；
- 二买/二卖：一类点后完成一个反向次级别走势，再完成首次回抽/回试；
- 三买：完成向上离开中枢，第一次完成的次级别回试最低点不低于 `ZG`；
- 三卖：完成向下离开中枢，第一次完成的次级别回抽最高点不高于 `ZD`。

买卖点是结构标签，不是无条件订单。

## 威科夫最低口径

先把横盘称为 `Trading Range` 候选，不预设为吸筹或派发。

### 潜在吸筹事件链

- Phase A：跌势停止，可能出现 `PS—SC—AR—ST`；
- Phase B：区间内反复测试和吸收；
- Phase C：可能出现Spring/Shakeout及Test，也可能没有Spring；
- Phase D：SOS后出现LPS/BU，需求逐渐占优；
- Phase E：被市场接受性地离开交易区，进入Markup。

### 潜在派发事件链

- Phase A：涨势停止，可能出现 `PSY—BC—AR—ST`；
- Phase B：区间内反复换手，供给逐渐显现；
- Phase C：可能出现UT/UTAD及测试，也可能没有UTAD；
- Phase D：出现SOW，反抽形成LPSY，供给逐渐占优；
- Phase E：被市场接受性地跌离交易区，进入Markdown。

事件需要“位置 + 当下量价 + 后续验证”。单根长影、放量或越界不能独立确认SC、Spring、UTAD等事件。

## 努力—结果

“努力”主要观察相对成交量、换手和持续时间；“结果”观察价差、收盘位置、净推进、越界幅度和后续延续。

| 努力 | 结果 | 初步解释 | 必须继续验证 |
|---|---|---|---|
| 放量 | 宽幅且收在方向有利端，持续推进 | 主动需求或供给有效 | 后续跟随、回试是否守住 |
| 放量 | 窄幅、长影或净推进很小 | 存在吸收或派发 | 下一段脱离方向，不能当场定性 |
| 缩量 | 窄幅、推进弱 | 无供给/无需求测试候选 | 所处位置和下一段响应 |
| 缩量 | 大幅推进或跳空 | 流动性真空，走势可能脆弱 | 回补、承接和后续量能 |

量能与同一标的、相近背景和同类时段比较。开收盘、涨跌停、停牌复牌和除权后的异常量需单独处理。

## 突破接受度

把有效突破拆成三道门：

1. **脱离**：价格有效收在边界外，不只是影线刺穿；
2. **延续**：后续执行层结构继续向突破方向推进，没有快速返回区间；
3. **接受**：第一次合理回试在新边界外止住，并重新向突破方向扩张。

只完成第一项时标为“突破候选”。“脱离 + 延续”或“脱离 + 回试守住 + 再启动”完成后，才把突破视为被市场接受。

假突破常见证据：

- 越界时努力大但推进小；
- 很快收回原区间；
- 再次测试越界方向时量价转弱；
- 随后向相反方向出现明确推进。

跌破后收回先称Spring候选；上破后收回先称UT候选。等待Test、SOS/LPS或SOW/LPSY等后续证据。

## 不可直接等同的概念

| 威科夫概念 | 不能直接等同于 | 正确关系 |
|---|---|---|
| Trading Range | 中枢 | 前者是供需行为区；后者由严格的次级别重叠定义 |
| Phase A—E | 缠论走势类型 | 一个描述供需阶段，一个描述递归几何结构 |
| Spring | 一买 | 可能共现，也可能只是区间下沿假突破 |
| Test/LPS/BU | 二买或三买 | 三类点必须满足缠论次级别完成和边界条件 |
| SOS/SOW | 中枢离开 | 可作为离开质量证据，但不能替代结构完成 |
| UT/UTAD | 一卖 | 区间假突破不要求存在严格上涨趋势背驰 |
| 努力大、结果小 | 缠论背驰 | 前者描述供需吸收/派发，后者有趋势和可比段前提 |
| Creek/Ice回测 | 三买/三卖 | 只有结构条件同时成立时才能双重标注 |

## 联立规则

- 用缠论决定级别、结构位置和定义边界；
- 用威科夫判断突破、回试和供需质量；
- 两者同向且有跟随时升级证据；
- 两者冲突时降级为等待，不选择更符合持仓愿望的一套；
- 用大层边界约束小层信号，用小层变化提供先行触发；
- 不把小层信号直接上纲为大层反转。
