## 先区分目标

- **做T降成本**：期末计划总持仓不增加，以波动差价降低经济回本价。
- **加仓摊平**：总风险敞口增加，不得伪装成做T。
- **风险减仓**：卖出后不承诺买回，以降低损失暴露为目标。

成本价只是账户变量，不是市场支撑。先判断结构，再选择目标。

## 交易制度与口径

执行前核对当期交易所和券商规则，包括：

- 新买证券何时可卖；
- 最小申报单位和零股处理；
- 涨跌幅、停牌和有效申报价格；
- 佣金、税费、过户费和最低收费；
- 可卖数量、现金可用时间和融资限制。

规则与费率会变化，优先使用交易所和券商的当前资料，不在技能中硬编码费率。

对A股普通股票，所谓当日正T通常依赖此前已有的可卖持仓：当日先买入，再卖出等量旧仓；新买入部分本身通常不能当日卖出。倒T则先卖出已有可卖持仓，再按条件买回。分析时明确实际卖出的是哪部分可卖数量。

不同社区可能把“正T、倒T”叫反。输出时始终同时写明“先买后卖”或“先卖后买”，不要只写简称。

## 适用门槛

仅在以下条件大致同时成立时讨论区间做T：

- 持仓层不是已确认的单边下跌或Markdown；
- 操作层存在可复核的中枢/交易区边界；
- 预期净波动足以覆盖全部费用、滑点和错误空间；
- 流动性允许目标数量成交；
- 不临近无法承受的公告、停复牌或跳空事件；
- 用户预先定义T仓上限和失效处理。

每套计划必须同时写清：

- 第一腿与第二腿的先后顺序；
- 每腿数量、价格触发和取消条件；
- 只成交一腿、部分成交或跳空越过价格时的处置；
- 底仓下限、单日/单轮风险上限和暂停条件。

以下情况停止做T：

- 边界不清或价格位于区间中部；
- 单边加速；
- 向下突破已被市场接受；
- 缠论与威科夫证据冲突；
- 连续执行失败说明原区间或触发逻辑失效。

## 倒T与正T

### 倒T：先卖后买

适合“不增加资金和总仓位”的目标。

风险：

- 卖出后价格直接向上，导致少持仓；
- 为恢复股数而追高，使经济成本上升。

纪律：

- 卖飞不追；
- 等待新的回试、LPS/BU或结构触发；
- 接受期末暂时减仓，不为凑股数破坏纪律。

### 正T：先买后卖

需要额外现金，并在盘中暂时增加风险敞口。只能在已有足够可卖旧仓、买入触发明确且失效距离可控时讨论。

风险：

- 买入后继续下跌；
- 旧仓未按计划卖出，正T变成加仓；
- 涨跌停、流动性或操作失误阻断闭环。

纪律：

- 预先指定卖出旧仓数量；
- 结构失效时执行风险处理，不把失败T仓长期化；
- 用户明确“不增加资金”时不推荐正T。

## 高抛和买回触发

### 高抛T仓

位置门槛：

- 接近交易区上沿、前高、供应区或中枢上方震荡外沿。

结构证据：

- 执行层顶分型确认、上涨段结束或满足定义的卖点候选。

量价证据：

- UT/UTAD候选；
- 买入努力增大但价格推进缩小；
- 上破快速收回区间；
- 反抽无需求并出现向下跟随。

失效：

- 上破后宽幅推进且持续站稳；
- 回试缩量守住新边界并再次扩张；
- 缠论形成确认的向上离开与相应三买结构。

失效后停止机械高抛；已卖出则等待新回试，不追价。

### 买回T仓

位置门槛：

- 接近交易区下沿、需求区或中枢下方震荡外沿。

结构证据：

- 执行层底分型确认、下跌段结束或满足定义的买点候选。

量价证据：

- Spring/Test候选；
- 卖出努力增大但向下推进缩小；
- 跌破后快速收回区间；
- 测试时价差与量能收缩，随后出现向上跟随。

失效：

- 放量宽幅跌破并继续推进；
- 反抽不能收回关键边界；
- 出现SOW/LPSY或确认的向下离开结构。

失效后取消买回，不把倒T变成补仓。

## 模式切换

| 市场状态 | 允许模式 |
|---|---|
| 潜在吸筹D/E + 向上结构确认 | 趋势持有为主，少做逆向高抛 |
| 中性交易区 + 单中枢震荡 | 上下沿双证触发时做T |
| 潜在派发D/E + 向下结构确认 | 停止低吸式自救，优先降低风险 |
| Markdown/确认下跌趋势 | 不用摊平替代风险处理 |

## 经济成本公式

设：

- 原总持仓 `Q` 股；
- 当前经济成本 `C` 元/股；
- T交易数量 `q` 股；
- 卖价 `Ps`；
- 买回价 `Pb`；
- 本轮全部费用和滑点 `F`。

当买回后总持仓恢复为 `Q`：

```text
单轮净收益 G = q × (Ps - Pb) - F
每股降本 ΔC = G / Q
新经济成本 C' = C - G / Q
保本价差 Ps - Pb > F / q
```

连续多轮且每轮结束后总持仓恢复为 `Q`：

```text
Cn = C0 - ΣGi / Q
```

若期末持仓数量发生变化，使用统一现金流账本：

```text
经济成本 =
（起始持仓成本总额 + 累计买入支出 - 累计卖出净收入 - 净分红）
÷ 当前持股数
```

券商显示成本可能采用不同的已实现盈亏归集方式。说明使用的是“经济回本价”，不要承诺界面数值完全一致。

历史复盘或回测时，分别记录 `event_time`、`confirm_time` 与最早现实可成交时刻；不得用确认前的极值、同根K线未知先后顺序或复权价模拟成交。优先使用下一可成交报价，并纳入部分成交、涨跌停、费用和滑点。

### 示例

原持仓成本88元，拿三分之一仓位做T：

- 88元卖、82元买：费用前每股总持仓降本约 `1/3 × 6 = 2` 元；
- 87元卖、83元买：约降 `1.33` 元；
- 89元卖、81元买：约降 `2.67` 元。

因此不能笼统写“每次必降2—3元”。

## 计算脚本

运行一轮：

```bash
python scripts/t_cost.py --shares 3000 --cost 88 \
  --trade 1000,88,82,20
```

运行多轮：

```bash
python scripts/t_cost.py --shares 3000 --cost 88 \
  --trade 1000,88,82,20 \
  --trade 1000,87,83,20
```

机器可读输出：

```bash
python scripts/t_cost.py --shares 3000 --cost 88 \
  --trade 1000,88,82,20 --json
```

`--trade` 的字段依次为 `股数,卖价,买回价,全部费用与滑点`。

## 复盘账本

每轮记录：

| 字段 | 内容 |
|---|---|
| 决策时刻 | 当时可见的时间与数据 |
| 位置 | 上沿/下沿/中枢/离开/回试 |
| 缠论证据 | 对象、级别、状态 |
| 威科夫证据 | 事件、努力—结果、跟随 |
| 计划 | 数量、触发、失效 |
| 实际成交 | 卖价、买价、费用、滑点 |
| 结果 | 净收益、每股降本、期末股数 |
| 纪律 | 是否追价、摊平或使用事后标签 |

参考当前市场规则时，优先查阅对应交易所正式文件；例如深市规则入口：
[深圳证券交易所法律规则](https://www.szse.cn/lawrules/)
